# TextBookMarketPlace
Group3TextbookApp is an Android application that allows users to list, browse, and search for textbooks. Users can enter textbook details, check for duplicates, and store book listings in an SQLite database.

Features:
Add new textbook listings (Title, Seller, Price, Copies, Bank Info)  Prevent duplicate entries before inserting into the database 
Browse available textbooks in a ListView  
Search textbooks by title or seller 
Store and retrieve textbook data using SQLite

Installation & Setup
Prerequisites:
Android Studio (latest version)
Java (Android SDK)
SQLite Database
Setup:
Clone the repository (or download the project)
Open the project in Android Studio.
Run the app on an emulator or a physical device.
Ensure permissions for Internet & Storage if required.
